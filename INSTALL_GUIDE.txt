===============================================
   دليل تثبيت نظام True Shield على استضافة خارجية
===============================================

📋 المتطلبات:
--------------
- Python 3.9 أو أحدث
- PostgreSQL 12 أو أحدث
- pip (مدير حزم Python)

📁 محتويات الحزمة:
------------------
- main.py                  : الملف الرئيسي للتطبيق
- templates/               : قوالب HTML
- static/                  : الملفات الثابتة (CSS, صور, أصوات)
- requirements.txt         : مكتبات Python المطلوبة
- backup_*/                : نسخة احتياطية من قاعدة البيانات

🔧 خطوات التثبيت:
-----------------

1. رفع الملفات:
   - ارفع جميع الملفات إلى السيرفر

2. إنشاء بيئة افتراضية (اختياري لكن موصى به):
   python -m venv venv
   source venv/bin/activate   (Linux/Mac)
   venv\Scripts\activate      (Windows)

3. تثبيت المكتبات:
   pip install -r requirements.txt

4. إعداد قاعدة البيانات PostgreSQL:
   - أنشئ قاعدة بيانات جديدة
   - احفظ بيانات الاتصال

5. إعداد متغيرات البيئة:
   export PGHOST="عنوان_السيرفر"
   export PGPORT="5432"
   export PGDATABASE="اسم_قاعدة_البيانات"
   export PGUSER="اسم_المستخدم"
   export PGPASSWORD="كلمة_المرور"

6. استيراد البيانات (اختياري):
   - ملفات JSON في مجلد backup_* تحتوي على:
     * codes_backup.json     : أكواد التفعيل
     * customers_backup.json : بيانات العملاء
   - يمكنك كتابة سكريبت لاستيرادها أو إضافتها يدوياً

7. تشغيل التطبيق:
   للتطوير:
   python main.py

   للإنتاج (مع gunicorn):
   pip install gunicorn
   gunicorn --bind 0.0.0.0:5000 main:app
